**Company Setup** → **Leave Types** is the list of leave your company offers — vacation, sick, maternity and so on. Requests are filed against these, and balances are kept per type.

## Adding a leave type

Choose **New leave type** and fill in:

- **Name** and **Code** — the code is a short label such as `VL`, unique in your company;
- **Default days / year** — what each person is entitled to each year, unless their own entitlement is changed on the balances tab;
- **Colour** — how the type is shown on requests and balances;
- **Paid leave** — whether it's paid;
- **Allow half-day** — whether a single day can be taken as a half;
- **Requires approval** — off, and requests of this type are approved the moment they're filed;
- **Active** — whether people can file it;
- a description.

> [!TIP]
> The Setup Guide can add the statutory and common leave types for you, ready to adjust.

## Changing a leave type

Edit a type at any time. Changing its **default days** changes the entitlement of everyone who doesn't have their own set for the year.

## Archiving and deleting

**Archive** a type you no longer offer; restore it from the archived list or the [Trash bin](/help/administration/trash-bin). A type that has requests against it can't be deleted permanently — archive it instead. If another type has taken its code while it was archived, change one of them before restoring.
