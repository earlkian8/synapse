**Company Setup** → **Performance Framework** holds everything an appraisal is scored against, in five tabs: **Frameworks**, **Rating scales**, **Criteria**, **Review cycles** and **Goal library**. They build on each other — a scale measures a criterion, and a framework is made of criteria — so they are explained here from the bottom up.

## Rating scales

A **rating scale** is _how_ something is measured:

- a **numeric** range, with a step (for example 1 to 5);
- a **percentage** (0–100), for targets;
- named **levels**, in order, each with a description of what it looks like in practice (for example _Developing_, _Proficient_, _Expert_).

Mark one scale as your default. A scale in use can't be deleted permanently.

## Criteria

A **criterion** is _what_ is measured — _Quality of work_, _Attendance and punctuality_, _Sales target_ — with the scale it is rated on and a default weight. The criteria list is a **catalogue**: frameworks choose from it, and renaming a criterion here updates every framework that uses it.

## Frameworks

A **framework** is the appraisal form itself:

- **Sections**, each with a weight — for example _Results_ 60% and _Behaviours_ 40%;
- the **criteria** in each section, each with a weight within its section. Choose them from the catalogue; a criterion can only appear once per framework. For something genuinely specific to one framework, add a **one-off** line — it keeps its own wording and stays out of the catalogue;
- **who it covers** — everyone, a department, a position, or an employment type;
- the **rating model**: your result bands, top down, each with a label, a lower threshold, a description and a colour — drawn live as the ladder appraisals will show;
- which reading the scorecard leads with.

Weights are relative twice over — a section's share of the appraisal, a line's share of its section — so the editor shows each line's resulting share of the whole, keeps running totals, and can split weights evenly for you.

When an appraisal is opened, the most specific framework covering the person is chosen: position, then department, then employment type, then everyone, with your default breaking ties. HR can always choose another.

## Goal library

The **goal library** holds the goals your company sets often, for example _Reduce ticket backlog_ or _Complete a certification_. Each entry has its wording, what success looks like, and how it's measured:

- **Progress to 100%**;
- **A number to reach**, from a start to a target in a unit (for example 120 tickets → 20 tickets).

When HR sets a goal, they can start from a library entry. The goal copies the entry's wording and target, so editing the entry later never changes a goal that's already been set. An entry you no longer use can be archived. See [Goals and check-ins](/help/workforce/goals-and-check-ins).

## Review cycles

A **review cycle** is the period appraisals belong to — for example _2026 Annual Review_ — with a start and end date and a status:

| Status     | Meaning                         |
| ---------- | ------------------------------- |
| **Draft**  | Being planned.                  |
| **Open**   | Appraisals can be opened in it. |
| **Closed** | Finished.                       |

Appraisals can only be opened while a cycle is **open**.

## Changing things later

An appraisal keeps the framework, sections, scales and bands it was opened under. Changes reach the **next** appraisals, never ones already opened. A framework that appraisals have used can't be deleted permanently — archive it instead.

> [!TIP]
> The Setup Guide offers three ready-made frameworks to start from, each fully customisable.
