An **onboarding program** is a checklist template. When someone is hired, their onboarding checklist is copied from the program that matches them best. Manage programs under **Company Setup** → **Onboarding Programs**.

## Creating a program

1. Choose **New program** and give it a **Program name** and a description.
2. Say who it is for: a **Department** (or any), and an **Employment type** (or any).
3. Add its tasks with **Add task**. For each: a title, a category — Paperwork, Equipment, Access, Orientation, Training, Compliance or Other — and **how many days after the hire starts** it is due. Use the arrows to put them in order.
4. Tick **Default program** if it should be used when nothing more specific matches, and **Active** to use it at all.

Because due dates are relative, the same program works for everyone: a task due "3 days after start" lands on the right date for each new hire.

## Which program a hire gets

The most specific active program wins:

1. one for their department **and** employment type;
2. one for their department;
3. one for their employment type;
4. the default program.

## Changing a program

Changes apply to checklists started afterwards. Checklists already started keep their tasks — edit those on the person's onboarding.

> [!TIP]
> The Setup Guide can add a standard onboarding checklist to start from.
