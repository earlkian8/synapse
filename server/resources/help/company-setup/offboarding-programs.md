An **offboarding program** is a clearance template: the sign-offs every exit needs — return the laptop, revoke system access, settle any cash advance, hand over documents — and the department that signs off each one. Manage them under **Company Setup** → **Offboarding Programs**.

## Creating a template

1. Choose **New template** and give it a name and a description.
2. Optionally narrow it to a **Department** and an **Exit type** — resignation, termination, retirement or end of contract.
3. Add its sign-offs. For each, choose who owns it:
    - a **department** — for example IT for equipment, Finance for final pay;
    - the **leaver's own department** — for handovers;
    - **nobody** — to be assigned when the exit is under way.
4. Tick **Default template** if it should be used when nothing more specific matches, and **Active** to use it at all.

## Which template an exit gets

When an exit starts, the most specific active template seeds its clearance:

1. one for the leaver's department **and** the exit type;
2. one for their department;
3. one for the exit type;
4. the default template.

More items can be added to an exit later — including from another template, with **Add items from a template** on the exit.

## Changing a template

Changes apply to exits started afterwards. Exits already in progress keep their checklist.

> [!TIP]
> The Setup Guide can add a standard exit clearance, already routed to IT, Finance and HR if you have departments with those codes.
