**Company Setup** → **Award Types** is the catalogue of awards your company gives — _Employee of the Month_, _Perfect Attendance_, _Customer Hero_ and so on. Recognitions are then given from [Awards and recognition](/help/workforce/awards-and-recognition).

## Adding an award type

Choose **New award type** and give it a name, a description of what it recognises, and an accent **colour** — it tints the award's badge everywhere it appears. Each type shows how many times it has been given.

> [!TIP]
> The Setup Guide can add the common award types for you.

## Retiring an award type

Switch a type to inactive to stop it being given while keeping its history; switch it back on to use it again.

## Archiving and deleting

**Archive** a type to take it off the list; restore it from the archived list. Past awards keep showing an archived type.

A type that has ever been given can't be deleted permanently — archive it instead, so the awards that used it keep their meaning.
