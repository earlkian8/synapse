# Data

Nothing in this directory except this file is committed. The promotion dataset is too
large for git, and the attrition surveys are people's responses, collected under a
consent notice, so they stay out of the repository. Obtain them from the project
maintainer and place them as below.

```
data/
├── raw/          source datasets, exactly as received; code only ever reads them
│   ├── attrition-survey-1.csv             attrition survey, export 1 (99 responses)
│   ├── attrition-survey-2.csv             attrition survey, export 2 (69 responses)
│   └── employee_promotion_prediction.csv  promotion + performance models (~100k rows)
├── processed/    derived datasets, regenerated by code; safe to delete
│   └── attrition-survey-merged.csv        both surveys merged and cleaned (155 rows)
└── archive/      datasets no model uses any more, kept for reference only
    ├── attrition-v2.csv                   IBM HR attrition (ADR 0021, retired by ADR 0030)
    └── employee_attrition_dataset_10000.csv  synthetic, no signal (retired)
```

`processed/attrition-survey-merged.csv` is written by the attrition notebook, or directly:

```bash
.venv/Scripts/python.exe -m synapse_ml.attrition.survey    # from model/
```

How the surveys are cleaned (who is kept, what is dropped, and why) is documented in
`synapse_ml/attrition/survey.py`.
