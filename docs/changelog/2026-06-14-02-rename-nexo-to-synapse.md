# 2026-06-14 — Rebrand: NEXO → SYNAPSE

The product is renamed from **NEXO** to **SYNAPSE** across the entire codebase —
UI, configuration, assets, identifiers, and documentation. This is a pure rename:
no behaviour changes.

## Highlights

- Every user-facing **NEXO** brand mention is now **SYNAPSE** (app name, auth page
  titles, welcome/footer, logo alt text, assistant name, notification copy).
- Internal identifiers carrying the old name were renamed in lock-step so callers
  and listeners still match — see Notes for the ones to be aware of.

## Backend

- `config/app.php` — `APP_NAME` default `NEXO` → `SYNAPSE`; `config/mail.php`
  from-name default follows.
- `composer.json` — package `nexo/nexo` → `synapse/synapse`, description updated.
- `app/Notifications/SystemNotification.php` — mail action/salutation
  ("View in SYNAPSE", "— The SYNAPSE Team").
- `app/Http/Controllers/UserManagement/UserController.php` — welcome notification
  title "Welcome to SYNAPSE".
- Assistant: `Assistant.php` system prompt, `AssistantController`,
  `AssistantConversation`, and the assistant migration comment now say
  "Synapse Assistant" / "Synapse HR platform".
- Seeders/ADRs/docs: the seeded super-admin email `dev@nexo.com` → `dev@synapse.com`
  (`DatabaseSeeder`, `RolePermissionSeeder`, `LeaveSeeder`); demo org "NEXO Demo Co"
  → "SYNAPSE Demo Co".

## Frontend

- Brand text in `app.tsx` (default `VITE_APP_NAME`), `welcome.tsx`,
  `auth-simple-layout.tsx`, all `pages/auth/*` `<Head>` titles, `app-logo*.tsx`,
  `app-footer.tsx`, and `notification-preferences.tsx`.
- Renamed identifiers (dispatcher **and** listener updated together):
  - window event `nexo:employee-mutated` → `synapse:employee-mutated`
    (`assistant.tsx` ↔ `pages/employees/index.tsx`).
  - CSS keyframe + class `nexo-row-flash` → `synapse-row-flash`
    (`resources/css/app.css` ↔ `employees-table.tsx`).
  - localStorage draft key prefix `nexo.assistant.draft.*` →
    `synapse.assistant.draft.*` (`assistant.tsx`).

## Assets

- `public/nexo-logo-transparent.png` → `public/synapse-logo-transparent.png`
- `public/nexo-logo-white-background.png` → `public/synapse-logo-white-background.png`
- References updated in `app.blade.php`, `app-logo-icon.tsx`, and
  `site.webmanifest` (manifest `name`/`short_name` → `SYNAPSE`).

## Docs

- `docs/README.md`, all `docs/modules/*`, `docs/decisions/*`, `docs/database/erd.md`,
  and prior changelog entries had their brand/identifier mentions updated so the
  documentation stays consistent with the renamed code.

## Notes

- **`.env` / `.env.example`:** `APP_NAME` is now `SYNAPSE`. The example template's
  `DB_DATABASE` was renamed to `synapse`, but the local `.env`'s `DB_DATABASE`
  (`staffa`) was left untouched — the physical database name is independent of the
  brand. Rename the DB and update `DB_DATABASE` only if you want to.
- **Old seeded account:** an already-seeded `dev@nexo.com` user keeps that address;
  re-seeding will create `dev@synapse.com`. Update existing data manually if needed.
- **localStorage drafts:** because the draft key prefix changed, any in-progress
  assistant drafts saved under the old `nexo.assistant.draft.*` keys won't be picked
  up; they're harmless orphans.
- Generated artifacts under `public/build/*` and the compiled view/log caches are
  git-ignored and were regenerated by `npm run build`; no manual edits there.
